## Featured Projects

A few things I've been building:

### 01. WhyDidItBreak?

**A developer tool that investigates why code broke after a change.**

A local-first Python CLI that connects newly failing tests to suspicious code changes and generates evidence-based regression reports.

- Python · Git · AST · pytest · Coverage.py
- No paid APIs or cloud dependency.

[Explore Repository →](https://github.com/varnesh123/WhyBroken)

### 02. PayPal Invoice Agent

**An AI-assisted invoice management and collection workflow.**

Explores invoice analysis, payment prioritization, reminder generation, human approval workflows, scheduling and audit logging.

- Python · FastAPI · Next.js · React · TypeScript · Supabase
- Mock and sandbox integration architecture.

[Explore Repository →](https://github.com/varnesh123/PayPal-invoice-agent)

### 03. Overdue Invoice Agent

**Automating overdue invoice follow-ups with human oversight.**

An agent workflow that analyzes overdue invoices, drafts context-aware reminders, escalates communication and verifies delivery.

- Python · Flask · SQLite · JavaScript · Tailwind CSS
- Human-in-the-loop approval and duplicate-send prevention.

[Explore Repository →](https://github.com/varnesh123/Overdue-invoice-agent)

### 04. Moodwave

**Music recommendations that adapt to how you feel.**

An experimental music recommendation system exploring mood-based recommendations, user feedback, personalization and contextual preferences.

- Python · NumPy · Recommendation algorithms
- Mood-based filtering and feedback-driven personalization.

[Explore Repository →](https://github.com/varnesh123/Music-Recommender-AI)
